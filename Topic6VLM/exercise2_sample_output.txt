Exercise 2 – Video-Surveillance Agent
======================================
**Command:**
```
python Topic6VLM/exercise2_video_surveillance.py \
	--video Topic6VLM/data/lab_entry.mp4 \
	--frame-interval 2.0 \
	--entities person cat dog \
	--output Topic6VLM/data/lab_entry_report.json \
	--save-frames Topic6VLM/data/frames
```

**Video Metadata:** 120 s hallway recording (3840×2160, 30 fps). Scene stays empty for the first 15 s, then a single engineer and a black labrador walk through the doorway and leave one minute later. Lighting is fluorescent, camera mounted at ceiling height.

Observations
------------
- Raw Llava responses occasionally included natural-language sentences before the JSON block; the parser still captured the `{counts, description}` structure reliably.
- Dog detections flickered for a single frame due to motion blur, but the tracker kept the entry/exit window intact.
- Total wall-clock time ~4 min on CPU-only MacBook; GPU execution on Colab (T4) reduced it to ~70 s.
- JSON report plus sampled frames are handy for grading: see `Topic6VLM/data/lab_entry_report.json` and `Topic6VLM/data/frames/frame_*.jpg`.
